# Models

Place a TAO 7.3-compatible Visual ChangeNet classification checkpoint here as:

```text
changenet_model_classify_latest.pth
```

There is no compatible pretrained full classification model published for this
workflow. Train from the public C-RADIOv2-B backbone; do not use the older 7.0
`visual_changenet_nvpcb_trainable_v1.0` checkpoint with TAO 7.3.
